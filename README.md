# Quiz App

A placement-oriented multiple-choice Quiz App built using HTML, CSS, and JavaScript.

## About the Project

This Quiz App is designed for practicing basic web development concepts that are useful for technical placement preparation.

The quiz contains 30 multiple-choice questions:

- 10 HTML questions
- 10 CSS questions
- 10 JavaScript questions

## Features

- Multiple-choice questions
- One question displayed at a time
- Next button
- Submit button
- Automatic score tracking
- Final score display
- Restart Quiz option
- Clean and responsive design
- Simple CSS transitions
- JavaScript-based question and score logic

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Quiz Structure

| Topic | Questions |

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start the quiz.
